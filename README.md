# 📌 Plataforma de Vendas Online

Este projeto oferece uma solução acessível para lojas e comércios venderem online com uma mensalidade muito baixa, que pode ser coberta já na primeira venda.

## 📂 Estrutura de Páginas

### 🏠 Páginas Gerais
- [x] `/` → **Início**
- [ ] `/produtos` → **Produtos**
- [ ] `/produto/{nome-do-produto}` → **Produto Individual**
- [ ] `/lojas` → **Lojas**
- [ ] `/loja/{nome-da-loja}` → **Loja Individual**
- [ ] `/sobre` → **Sobre**
- [ ] `/planos` → **Planos e Preços**
